Privacy

Last updated 2026-11-08.

Short version: this game collects nothing about you. There are no accounts, no ads, no analytics, no tracking cookies and no third-party scripts.

What stays on your device

Your progress (dives, scores, settings and Codex finds) is saved in your own browser using local storage. It never leaves your device unless you copy a save code or download a save file yourself. You can erase it any time in Settings, or by clearing this site's data in your browser.

Save codes

A save code contains only your game progress, including the answers you typed. Share it only with people you trust with that.

The web host

Like every website, this one is delivered by a hosting provider, which may briefly process technical data such as your IP address and browser type to deliver pages and protect against abuse. The game itself does not see or keep that data. See your host's policy: GitHub / Cloudflare.

Children

The game is suitable for all ages and collects no personal information from anyone.

Changes

If this ever changes (for example, optional accounts or leaderboards), this page will be updated first and the change will be explained in the game.
